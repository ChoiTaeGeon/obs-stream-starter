# OBS 24시간 방송 자동 재시작 프로그램 (macOS Intel/Apple Silicon)

맥북 환경에서 OBS Studio로 24시간 연속 방송을 송출할 때, 지정된 시간(기본 10시간)마다 방송을 안전하게 중단하고 자동으로 재시작해주는 원클릭 배치 프로그램입니다.

---

## 🚀 빠른 시작 (원클릭 실행)

1. **최초 1회 실행 권한 부여 (필수)**
   맥의 보안 정책상 다운로드받은 스크립트는 실행 권한이 필요합니다. 터미널을 열고 본 폴더 경로에서 아래 명령어를 한 번만 실행해주세요:
   ```bash
   chmod +x start_obs_restarter.command
   ```

2. **OBS WebSocket 활성화 확인**
   - OBS Studio 실행 -> 상단 메뉴 **[도구(Tools)]** -> **[WebSocket 서버 설정(WebSocket Server Settings)]** 클릭
   - **`WebSocket 서버 활성화(Enable WebSocket server)`** 체크
   - 서버 포트: `4455` (기본값)
   - *인증 활성화(비밀번호)가 체크되어 있다면 비밀번호를 복사하거나, 체크를 해제하시면 더 간편합니다.*

3. **원클릭 실행**
   - Finder(파인더)에서 **`start_obs_restarter.command`** 파일을 **더블클릭**하면 끝!
   - 필요한 가상환경과 라이브러리를 자동으로 설치하고 즉시 10시간 타이머 카운트다운을 시작합니다.

---

## ⚙️ 시간 및 동작 설정 변경 방법 (배치파일 수정)

`start_obs_restarter.command` 파일을 텍스트 편집기(메모장, TextEdit, VS Code 등)로 열면 최상단에 직관적인 설정 구역이 있습니다:

```bash
# ==============================================================================
# [★ 사용자 설정 영역 - 원하는 값으로 수정하세요]
# ==============================================================================
# 1. 재시작 주기 (시간 단위, 소수점 가능)
#    예: 10 = 10시간마다 / 0.5 = 30분마다 / 0.016 = 약 1분마다(테스트용)
RESTART_INTERVAL_HOURS=10

# 2. 재시작 방식 선택:
#    - "stream" : OBS 프로그램은 켜두고 방송 송출만 중단 후 재시작 (권장)
#    - "app"    : OBS 프로그램 자체를 종료 후 재실행 (메모리 누수 방지용)
MODE="stream"

# 3. 방송 중단 후 재시작 전 대기 시간 (초 단위)
COOLDOWN_SECONDS=10

# 4. OBS WebSocket 비밀번호 (OBS 설정에서 비밀번호를 지정한 경우에만 입력)
OBS_WS_PASSWORD=""
```

- **시간을 변경하고 싶을 때**: `RESTART_INTERVAL_HOURS=10`의 숫자를 원하는 시간(예: `8`, `12`, `6` 등)으로 변경하고 저장(`Cmd + S`)하면 바로 적용됩니다.

## 💡 두 가지 재시작 모드 안내

| 모드 | 설명 | 추천 상황 |
| :--- | :--- | :--- |
| **`stream`** (기본 권장) | OBS 프로그램은 켜둔 채 방송 송출(스트림)만 중단 -> 10초 대기 -> 방송 시작 | 플랫폼 세션 갱신, 다시보기(VOD) 쪼개기, 네트워크 정리 |
| **`app`** | OBS 프로그램 자체를 완전히 종료 -> 10초 대기 -> OBS 재실행 및 방송 시작 | 장시간 송출로 인한 OBS 메모리 누수 및 오디오/비디오 싱크 밀림 해결 |

> **`app` 모드 사용 시 주의사항**:
> OBS 설정 -> [일반] 탭에서 **"프로그램 시작 시 자동으로 방송 시작"** 옵션이 체크되어 있거나, 본 스크립트의 CLI 인자(`--startstreaming`)를 통해 자동 송출됩니다.
