# OBS 24시간 방송 자동 재시작 프로그램 (macOS Intel/Apple Silicon)

맥북 환경에서 OBS Studio로 24시간 연속 방송을 송출할 때, 지정된 시간(기본 10시간)마다 방송을 안전하게 중단하고 자동으로 재시작해주는 원클릭 배치 프로그램입니다.

---

## 🚀 빠른 시작 (원클릭 실행)

1. **최초 1회 실행 권한 부여 (필수)**
   맥의 보안 정책상 다운로드받은 스크립트는 실행 권한이 필요합니다. 터미널을 열고 본 폴더 경로에서 아래 명령어를 한 번만 실행해주세요:
   ```bash
   chmod +x *.command
   ```

2. **OBS WebSocket 활성화 확인**
   - OBS Studio 실행 -> 상단 메뉴 **[도구(Tools)]** -> **[WebSocket 서버 설정(WebSocket Server Settings)]** 클릭
   - **`WebSocket 서버 활성화(Enable WebSocket server)`** 체크 (포트: `4455`)

3. **용도에 맞는 원클릭 배치파일 더블클릭 실행**
   - **`start_obs_restarter.command`**: 방송(10시간) 및 녹화(2시간) **통합 자동 재시작**
   - **`start_record_restarter.command`**: 오직 **녹화만 2시간 단위로 자동 재시작** (방송 송출에는 영향 없음)

## ⚙️ 시간 및 동작 설정 변경 방법 (배치파일 수정)

`start_obs_restarter.command` 파일을 텍스트 편집기(메모장, TextEdit, VS Code 등)로 열면 최상단에서 손쉽게 설정을 변경할 수 있습니다:

```bash
# ==============================================================================
# [★ 사용자 설정 영역 - 원하는 값으로 수정하세요]
# ==============================================================================
# 1. 방송(Stream) 자동 재시작 설정
ENABLE_STREAM_RESTART=true      # 방송 자동 재시작 사용 (true / false)
STREAM_INTERVAL_HOURS=10        # 방송 재시작 주기 (기본 10시간, e.g. 10 = 10시간, 0.5 = 30분)

# 2. 동영상 녹화(Recording) 자동 재시작 설정
ENABLE_RECORD_RESTART=false     # 녹화 자동 재시작 비활성화 (필요 시 true로 변경)
RECORD_INTERVAL_HOURS=2         # 녹화 재시작 주기 (기본 2시간 단위, e.g. 2 = 2시간, 1 = 1시간)

# 3. 쿨다운 대기 시간 (초 단위)
STREAM_COOLDOWN_SECONDS=10      # 방송 중단 후 재시작 전 대기 시간 (초)
RECORD_COOLDOWN_SECONDS=3       # 녹화 중지 후 새 녹화 시작 전 디스크 flush 대기 시간 (초)

# 4. 재시작 방식 선택:
#    - "stream" : OBS는 켜두고 방송/녹화만 안전하게 재시작 (권장 / 초경량 CPU 0% 최적화)
#    - "app"    : OBS 프로그램 앱 자체를 완전히 껐다 켜기
MODE="stream"

# 5. OBS WebSocket 연결 설정 (MODE="stream" 일 때 사용)
OBS_WS_HOST="127.0.0.1"
OBS_WS_PORT=4455
OBS_WS_PASSWORD=""              # OBS에서 비밀번호를 설정한 경우에만 입력
```

- **방송 주기 변경**: `STREAM_INTERVAL_HOURS=10`을 원하는 시간(예: `8`, `12` 등)으로 수정
- **녹화 주기 변경**: `RECORD_INTERVAL_HOURS=2`를 원하는 시간(예: `1`, `2`, `4` 등)으로 수정
- **녹화 재시작 끄기/켜기**: `ENABLE_RECORD_RESTART=false` 또는 `true`

## 💡 두 가지 재시작 모드 안내

| 모드 | 설명 | 추천 상황 |
| :--- | :--- | :--- |
| **`stream`** (기본 권장) | OBS 프로그램은 켜둔 채 방송 송출(스트림)만 중단 -> 10초 대기 -> 방송 시작 | 플랫폼 세션 갱신, 다시보기(VOD) 쪼개기, 네트워크 정리 |
| **`app`** | OBS 프로그램 자체를 완전히 종료 -> 10초 대기 -> OBS 재실행 및 방송 시작 | 장시간 송출로 인한 OBS 메모리 누수 및 오디오/비디오 싱크 밀림 해결 |

> **`app` 모드 사용 시 주의사항**:
> OBS 설정 -> [일반] 탭에서 **"프로그램 시작 시 자동으로 방송 시작"** 옵션이 체크되어 있거나, 본 스크립트의 CLI 인자(`--startstreaming`)를 통해 자동 송출됩니다.

## ❓ 자주 묻는 질문 (FAQ) & 트러블슈팅

### Q. 왜 유튜브는 스트림키 대신 '방송 설정 관리'로 새 방송을 만들어야 하나요?
- **이유 (유튜브 12시간 제한)**: 유튜브 라이브는 **12시간을 초과하면 다시보기(VOD)가 저장되지 않거나 영상이 잘리는 문제**가 있습니다.
- **해결책 (본 프로그램 자동화 기능 탑재)**:
  - 본 프로그램은 방송 재시작 시 저 팝업을 감지하여 **[방송 설정 관리] $\rightarrow$ [새 방송 생성 및 시작] 버튼을 맥북이 자동으로 클릭**하도록 구현되어 있습니다!
  - 이를 통해 **기존 10시간 방송은 종료되어 유튜브에 정상 VOD로 저장**되고, **새로운 10시간 방송이 즉시 시작**되어 VOD가 계속 안전하게 보존됩니다.
- **필수 설정 (최초 1회 macOS 권한 허용)**:
  - 맥OS 보안상 다른 앱의 버튼을 자동으로 클릭하려면 권한이 필요합니다:
  - 맥북 **[시스템 설정]** -> **[개인정보 보호 및 보안]** -> **[손쉬운 사용(Accessibility)]** 이동
  - **`터미널(Terminal)`** 앱의 스위치를 **ON(허용)**으로 켜주세요.
